Something else? Report an issue ↗
How does Avero send commands?+

When you choose Send, Avero identifies the signed Roblox desktop player, brings its window forward, checks focus, and enters your command using normal Windows keyboard input. Escape or a focus change stops subsequent input. Keep your intended ER:LC session open with menus closed. The connection test only finds and focuses the window; it sends no keys.

Does “Sent” mean the command worked?+

“Sent” means the local input sequence completed. Avero cannot independently confirm that chat opened or the game accepted the command. Check the outcome in Roblox before retrying. Successful command execution in a live game was not tested for this release.

Which commands can I use?+

The catalog includes 45 sourced actions. Your permissions, server features, and game updates affect availability; the in-game :commands list is the final reference. Warning message explicitly uses :pm, not a native :warn command. Ban reasons are recorded locally. Custom text that would change during command generation is blocked from automatic sending; you can still copy it.

What happens to my data?+

Presets, settings, saved reasons, and history stay on your device. Recent Players holds manually entered usernames for the current session only; it is not an online player list. Avero does not request Roblox passwords or account credentials.

Can I keep my existing settings?+

Yes. Close Avero before upgrading. Version 1.1.1 preserves existing presets, preferences, and history, while adding defaults for the new tools. The portable version uses the same local data location.
