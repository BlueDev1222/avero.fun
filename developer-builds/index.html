CAD Alpha tb1.0.0

Internal test build of Avero CAD. Not currently available for public download.

Developer notes

Early testing has identified significant problems. This build is not ready for public release.

Known issues

  • API integration is completely broken.
  • Automatic message sending is not working correctly.
  • Server creation is malfunctioning.
  • Database connections are unreliable.
  • Startup loading screen does not load correctly.
  • Moderation logs are incorrectly formatted.
  • Voice chat (VC) checks are not being read.
  • Map system loads the old ERLC map.
  • Discord bot fails to check usernames.
  • Discord bot does not rename members to their Roblox usernames.
  • Additional issues remain under investigation.
